# Code as forgery

Plagiarism, licence-laundering, and a git history that lies — SLOP2474, week 8

---

{/* _class: impact */}

# Software has its own forms of forgery, and they behave like the material ones.

Plagiarised code with identifying comments stripped is a copy with the note
removed — exactly like an unsigned canvas passed off as a master's.

---

## The note, in a codebase

- plagiarism: the note is the missing attribution
- rewritten history: provenance fabrication with a different tool
- licence-laundering: a forged chain of ownership

---

## Where the analogy breaks

You can't run a mass spectrometer on a git log. But you can diff it — and
diffing scales in a way chemistry never will.

---

## The digital descendants of a connoisseur's checklist

Blame, provenance attestation, dependency graphs: check the parts of the
object a forger has no reason to have thought about.
